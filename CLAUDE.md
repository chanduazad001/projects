# projects — public Project Portfolio

Public site at `/projects/`, reached from the hub's **Projects** card. Group rules in `../CLAUDE.md` apply.

## What this repo is
An **index**, not a code repo. It lists public project repos by category: Python, Cloud, DevSecOps, AI. Each project ships as its own public repo (`<category>-<name>`); this page links to it.

## Rules
- Each project entry: name, one-line problem it solves, stack tags, status (`building` / `shipped`), link to repo and live demo if any.
- Never list or describe private builds from `../../private/` unless a sanitised public showcase repo exists and I've approved it.
- Keep categories fixed at Python, Cloud, DevSecOps, AI unless I ask to change them.
- Every link must resolve. After editing, list each link and confirm the target repo exists (`gh repo view chanduazad001/<repo>`).

## Before committing
Build or open locally and check every category renders and every link works.
